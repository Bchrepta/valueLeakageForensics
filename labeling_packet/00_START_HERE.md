Rubric + CoTs + filled labels for the Donation Bet rescue analysis.

Labeling is **done** for required RESCUEs (102) and Claude controls (20). See `results/ben_labels.csv`.

| Path | Purpose |
|------|---------|
| `01_CONTEXT.md` | Experiment setup |
| `02_RUBRIC.md` | Label definitions |
| `03_HOW_TO_LABEL_ONE_SAMPLE.md` | How a row was labeled |
| `samples/*.md` | CoTs (`sample_id` searchable) |
| `results/ben_labels.csv` | Filled labels (canonical) |
| `results/labels.csv` | Same as `ben_labels.csv` |
| `results/labels_template.csv` | Empty template |
| `COUNTS.md` | Row counts by model/bucket |
